! Allegro dark mode for uBlock Origin (allegro.pl)
!
! Design
!  Allegro paints its UI through the "metrum" design-system color tokens
!  (--m-color-*), defined on the page and switched to dark by an extra sheet
!  metrum-core/metrum-dark-theme-*.m.css that Allegro only loads AFTER the user
!  picks "motyw urządzenia" (DEVICE) in the display-settings modal, and only
!  inside @media (prefers-color-scheme: dark). That dark sheet re-defines the
!  semantic tokens on .ceolg5 (a class present on <body>) / .opbox-fragment.
!  This list re-defines the SAME tokens unconditionally on :root and body, so
!  the dark palette applies regardless of the account/preference setting and
!  before paint (token overrides apply early -> no flash, nothing reverts).
!  Values below are Allegro's own dark values, resolved to concrete colors from
!  metrum-core (base palette + opacity) overlaid with the dark theme sheet.
!  No :matches-css() is used (same reasoning as the OLX list).
! Palette follows Allegro dark: black/charcoal surfaces (#000 / #222 / #2e2e2e),
! near-white text, orange accent #ff5a00, teal secondary.
!
! NOTE: this only re-colors token-driven surfaces/text/borders/accents. Some
! components hard-code colors or use SVG/raster assets; add targeted :style()
! hooks below as you spot leftovers (same approach as olx_darkmode.txt).
